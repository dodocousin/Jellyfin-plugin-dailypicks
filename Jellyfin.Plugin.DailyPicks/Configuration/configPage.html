Daily Picks

Movies and shows picked every day at midnight (server time).

Used when the library is created. To rename an existing library, rename it in Dashboard → Libraries.

How titles are picked

Smart: each user gets their own picks in the web row. The TV library gets household picks, from titles every user is allowed to see.
The rest are random discoveries, so picks don't get stuck in one genre. Users with no history yet get popular and random picks.
For example "Because you watched Coraline", under the poster in the web row.

Users whose viewing shapes the picks

Untick guest or shared accounts. They still get picks; their viewing just doesn't shape the household picks or "popular".

Where picks show up

Browser, Jellyfin Media Player, LG webOS and Samsung Tizen. Users must refresh the page after installing the plugin.
Android TV, Fire TV, Roku and Apple TV show it as a "Recently added in Daily Picks" home row. It holds links to your files (a "Jellyfin Daily Picks" folder at the root of each media drive), not copies. Unchecking it deletes the library and those folders; your files are never touched.

PNG, JPEG or WebP, up to 10 MB. A wide 16:9 picture (e.g. 960×540) fits the tile best. It is applied as soon as it is uploaded.
